# Elle Clinic — by Dr Elmira

Design prototype for an independent London aesthetics clinic.

## Preview status

This is a design preview, not an operational booking website. Booking buttons only open a demonstration message. Prices, address and contact details are not yet final. Photographs depict AI-generated illustrative models, not the doctor, patients or treatment results.

## Local use

Open `index.html` in a modern browser. No installation or internet connection is needed.

## GitHub Pages

Serve the root of the `main` branch. All asset paths are relative and fragment navigation works under a project URL. `.nojekyll` disables Jekyll processing.

## Editing

- `index.html`: shared page structure
- `styles.css`: colours, typography and responsive styling
- `app.js`: page content and navigation
- `assets/`: photographs, favicon and logo concept

No analytics, payment processing or patient data collection is included. A noindex directive requests exclusion from search engines but does not make this public preview private.

Clinical content, exact qualification titles, applicable registrations, business details, privacy information and patient policies require final review before the clinic website launches.
